# /iterate — 真实用户视角循环迭代技能

## 触发

用户说"迭代"、"挑刺"、"优化循环"、"iterate"、"polish"，或任何暗示需要多轮改进的请求。

## 核心理念

- **道德经为道**：大道至简、自然、无为。去掉一切用户不需要的。水利万物而不争 — UI/功能服务用户而不炫技。少则得，多则惑。
- **孙子兵法为术**：知己知彼（深入了解用户场景）、先胜后战（设计先于编码）、兵贵神速（交互成本最小化）、因敌变化而取胜（根据反馈快速转向）。
- **乔布斯标准**：奶奶能不能用？有没有 insanely great 的感觉？每一个像素、每一个交互都有存在的理由吗？

## 执行流程

每触发一次 `/iterate`，执行 N 轮循环（默认 10 轮，用户可指定）：

### 每轮结构

```
1. 选定用户画像（每轮不同）
2. 以该用户身份走完整流程
3. 狠狠挑刺：
   - 按钮位置合理吗？大小够不够？
   - 文案清晰吗？新手看得懂吗？
   - 反馈及时吗？等待时知道发生了什么吗？
   - 出错了怎么办？能恢复吗？
   - 有没有死角、断头路？
   - 颜色对比度够吗？暗模式呢？
   - 手机上能用吗？单手够得到关键按钮吗？
   - 加载慢了会怎样？网断了呢？
4. 列出具体问题（精确到组件/行号/像素）
5. 实现修复
6. 验证测试通过 + 覆盖率不降
7. 用道德经/孙子兵法/乔布斯标准总结本轮哲学收获
```

### 用户画像池（每轮随机或顺序选取）

| # | 画像 | 核心诉求 |
|---|------|----------|
| 1 | 首次用户（从没见过这个产品） | 10 秒内理解价值、零学习成本上手 |
| 2 | 忙碌职场人（通勤中用手机） | 单手操作、快速获取结果 |
| 3 | 深度研究者（大量笔记） | 高效导航、精准检索、批量操作 |
| 4 | 退休老人（视力下降） | 大字体、高对比、简单流程 |
| 5 | 非母语用户（中英混用） | 术语可理解、有上下文提示 |
| 6 | 无障碍用户（屏幕阅读器） | ARIA 完整、键盘可达、语义清晰 |
| 7 | 极度不耐烦的人（2 秒注意力） | 即时反馈、零等待感、进度可见 |
| 8 | 完美主义设计师 | 像素对齐、间距统一、动效克制 |
| 9 | 乔布斯本人 | 去掉一切不必要的。再去掉一层。 |
| 10 | 你的竞品用户（刚从 Notion/Readwise 过来） | 不比人差、有独特亮点 |

### 挑刺维度清单

每轮至少检查以下维度：

- [ ] **信息架构**：用户能在 3 秒内找到想要的功能吗？
- [ ] **首次体验**：不看说明能完成核心任务吗？
- [ ] **错误处理**：每个可能失败的地方都有友好提示吗？
- [ ] **加载状态**：超过 300ms 的操作有骨架屏/进度吗？
- [ ] **空状态**：没有数据时显示什么？有引导吗？
- [ ] **触摸目标**：所有可点击元素 >= 44px 吗？
- [ ] **对比度**：文字 >= 4.5:1、大文字 >= 3:1 吗？
- [ ] **响应式**：375px / 768px / 1440px 都正常吗？
- [ ] **动效**：有意义吗？尊重 prefers-reduced-motion 吗？
- [ ] **文案**：没有术语、没有歧义、动词开头吗？
- [ ] **一致性**：相同操作在不同地方行为一样吗？
- [ ] **可逆性**：危险操作有确认吗？能撤销吗？
- [ ] **性能**：首屏 < 1s？交互响应 < 100ms？

## 输出格式

每轮输出：

```markdown
## 第 N 轮：[画像名称]

### 道（哲学层）
> 道德经引用 + 本轮简约化方向

### 术（战术层）
> 孙子兵法引用 + 具体攻击点

### 发现的问题
1. [严重程度] 具体问题描述（文件:行号 或 组件名）
2. ...

### 修复
- 改了什么、为什么这样改

### 乔布斯点评
> 一句话：这个改动让产品更接近"insanely great"了吗？
```

## 约束

- 每轮必须产出**真实代码改动**，不纸上谈兵
- 测试覆盖率不得低于 90%
- 迭代完毕后自动提交到 main 或创建 PR（根据用户偏好）
- UI 和功能都可以改，不限于视觉层
- 如果连续 2 轮没有实质性发现，可以提前结束并说明原因

## 参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 轮数 | 10 | `/iterate 20` 执行 20 轮 |
| 范围 | 全栈 | `/iterate ui` 只迭代 UI，`/iterate backend` 只迭代后端 |
| 严格度 | 极高 | `/iterate mild` 降低挑刺强度 |
