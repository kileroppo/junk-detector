# 鉴真 - Chrome Web Store Listing

## 名称
鉴真 - 内容质量检测

## 简短描述 (132 chars max)
一眼看穿垃圾信息。本地规则引擎实时检测诈骗、软文和情绪操纵内容，保护你的阅读时间。

## 详细描述
鉴真帮助你在浏览微信公众号、知乎、小红书、掘金、微博等平台时，实时识别低质量内容。

核心功能：
- 🚨 实时检测诈骗话术和虚假投资信息
- ⚠️ 识别隐性广告和商业软文
- ✅ 标记优质内容，节省你的时间
- 🔒 完全本地运行，不上传任何浏览数据

## 分类
Productivity
