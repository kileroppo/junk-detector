# 鉴真 Brand Identity

## 名称

**鉴真** (Jianzhen) — "辨别真伪"

灵感来源：唐代高僧鉴真，六次东渡，矢志不渝。
如同鉴真大师以坚韧求真，我们以技术鉴别信息真伪。

## 标语 (Tagline)

**鉴真 — 一眼看穿**

此标语应统一使用于：
- README.md 顶部
- Chrome Web Store 商店描述
- API 文档首页
- CLI 启动横幅
- 官网 landing page

## 价值主张

**一眼看穿垃圾信息**

## 定位

面向中文互联网用户的内容质量检测工具。
零配置即用，规则引擎本地运行，保护隐私，毫秒级响应。

## 使用场景

- 日常浏览时快速判断文章可信度
- 开发者集成到内容审核流水线
- AI 工具链中作为信息过滤层

## CLI 命名

保持 `junk-detector` 命令名不变（向后兼容），
显示名使用"鉴真"。

## 鉴真 vs 其他工具

| 工具 | 定位 | 鉴真的差异 |
|------|------|-----------|
| Perspective API (Google) | 检测仇恨言论和有毒评论 | 鉴真专注中文互联网的骗局、软文和垃圾信息 |
| NewsGuard | 英文新闻网站可信度评级 | 鉴真做内容级别分析，而非网站级别；覆盖中文 |
| CleanBrowsing | DNS 级别内容过滤 | 鉴真分析文字内容本身，不是域名黑白名单 |
| 各平台举报系统 | 被动等待用户举报 | 鉴真主动实时检测，无需等待社区举报 |

**一句话定位**: 为中文互联网用户提供实时、本地、隐私优先的内容质量检测。
