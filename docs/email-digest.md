# 周报邮件功能 (规划)

## 概述

每周自动发送个人阅读质量报告邮件。

## 邮件内容

```
主题: 鉴真周报 - 本周你阅读了 47 篇内容

────────────────────────────────

📊 本周阅读质量报告

检测内容: 47 篇
识别可疑: 6 篇 (12.8%)
标记危险: 2 篇 (4.3%)

🏆 连续使用: 12 天

────────────────────────────────

⚠️ 本周重点提醒:

1. [文章标题] - 检测到投资诈骗话术
   来源: mp.weixin.qq.com

2. [文章标题] - 疑似软文推广
   来源: xiaohongshu.com

3. [文章标题] - 情绪操纵内容
   来源: zhihu.com

────────────────────────────────

💡 本周信息素养小贴士:
"看到'限时''名额有限'等字眼时，
 给自己 24 小时冷静期再做决定。"
```

## 配置

在扩展设置页面启用:
- 开关: 接收周报邮件
- 邮箱地址输入
- 发送时间: 每周一 9:00

## 技术实现 (未来)

- 扩展收集周数据存入 chrome.storage.local
- 需要后端邮件服务 (SendGrid/AWS SES)
- 或使用 Chrome 通知 API 做本地周报替代
