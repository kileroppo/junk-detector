## 功能模块

### 1. 实时监控
- API 调用量实时曲线
- 错误率告警 (>1% 触发)
- 响应时间 P50/P95/P99

### 2. 用户管理
- 用户列表与用量统计
- API Key 管理 (创建/撤销)
- 配额调整

### 3. 内容审计
- 最近标记为"危险"的内容样本
- 误报/漏报统计
- 规则命中率排行

### 4. 系统配置
- 规则热更新
- LLM 模型切换
- 限流策略调整
