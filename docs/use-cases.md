# 鉴真 使用场景

## 场景一：记者验证消息来源

**背景**: 新闻记者收到一篇来源不明的"独家爆料"，需要快速判断可信度。

**使用方式**:
```bash
junk-detector quick --text "转发的消息内容..." --rules-only
```

**价值**: 在截稿前几秒钟内获得初步风险评估，决定是否需要进一步核实。
鉴真不能替代事实核查，但能快速标记明显的造谣/诈骗特征。

---

## 场景二：家长保护孩子的阅读内容

**背景**: 青少年在社交平台阅读大量内容，家长希望帮助孩子识别不良信息。

**使用方式**: 安装鉴真浏览器扩展，自动在知乎、小红书等平台标记可疑内容。

**价值**: 不是"屏蔽"内容（那会引起反感），而是给出可视化提示，
培养孩子的信息素养。"看到红色标记时，想一想这篇文章的目的是什么。"

---

## 场景三：企业审核用户生成内容

**背景**: 社区平台需要审核用户发布的帖子，人工审核成本高且延迟大。

**使用方式**:
```python
from sdk.python import JianzhenClient

client = JianzhenClient(api_key="enterprise-key")

# 批量审核新帖子
for post in new_posts:
    result = client.score(post.content)
    if result["overall_score"] < 40:
        post.flag_for_review()
```

**价值**: 自动标记高风险内容进入人工审核队列，
将审核员的精力集中在真正需要判断的边界案例上。
