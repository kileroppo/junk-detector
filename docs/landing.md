# 鉴真 -- 一眼看穿垃圾信息

## 为什么需要鉴真？

中文互联网充斥着诈骗、软文、标题党。
你的时间不应该浪费在垃圾信息上。

鉴真帮你在毫秒内识别低质量内容，让你专注于真正有价值的信息。

## 核心能力

- 🚀 毫秒级响应 -- 规则引擎本地运行，无需等待
- 🔒 保护隐私 -- 无需上传内容到云端（规则检测模式）
- 🎯 精准识别 -- 201+ 关键词 + 9 维度评分
- 🧩 随处集成 -- CLI / API / Chrome 扩展 / MCP

## 使用方式

### 命令行

```bash
pip install junk-detector
junk-detector quick --text "想要财富自由吗？加入我们的投资群..."
# 🚨 疑似垃圾内容 (score: 5)
```

### Chrome 扩展

安装后自动检测微信公众号、知乎、小红书、掘金、微博文章。
浮动指示器实时显示内容质量评分。

### API

```bash
# 试用（无需认证）
curl http://localhost:8000/demo

# 正式评分
curl -X POST http://localhost:8000/score \
  -H "Content-Type: application/json" \
  -d '{"text": "你的文本内容..."}'
```

### AI 工具集成

支持 Cursor、Claude Code、VSCode Copilot 等 AI 工具直接调用。

```json
{
  "mcpServers": {
    "junk-detector": {
      "command": "junk-detector",
      "args": ["mcp-server"]
    }
  }
}
```

## 检测维度

| 维度 | 说明 |
|------|------|
| 诈骗概率 | 识别投资骗局、传销话术 |
| 软文概率 | 识别隐性广告、带货文案 |
| 情绪操纵 | 识别标题党、焦虑贩卖 |
| AI 生成 | 检测机器批量产出内容 |
| 可信度 | 检测伪权威、阴谋论 |

## 谁在用

- 内容审核团队 -- 提升审核效率
- 独立开发者 -- 为自己的产品添加内容过滤
- 信息安全研究者 -- 分析垃圾信息传播模式
- 关注信息质量的普通用户 -- 保护自己的注意力

## 技术优势

```
文本输入 → 规则引擎 (201+ 关键词, <1ms)
              │
              ├── 高置信度 → 直接返回（零成本）
              │
              └── 低置信度 → LLM 精细评分（9 维度）
```

- 规则优先，LLM 兜底：99% 的明显垃圾内容无需 LLM 调用
- 零配置即用：`pip install` 后直接可用
- Unix 哲学：管道友好，exit code 有语义

## 开始使用

```bash
pip install junk-detector

# 30 秒体验
junk-detector quick --text "月入百万 躺赚 限时免费 加微信"
```
